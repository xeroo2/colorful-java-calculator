# 🎨 Colorful Calculator

![Language](https://img.shields.io/badge/Language-Java-blue)
![Status](https://img.shields.io/badge/Status-Complete-brightgreen)
![UI](https://img.shields.io/badge/Interface-Colorful-lightpink)


Colorful Calculator is a simple, fun, and colorful calculator built with Java Swing.
It performs basic arithmetic operations like addition, subtraction, multiplication, and division – all with a vibrant user interface.

📋 Features
Basic operations: +, -, *, /

Random colorful buttons every time you run it

Single window enforced using the Singleton pattern

Clear and reset functionality

Error handling for division by zero

Responsive and user-friendly GUI
